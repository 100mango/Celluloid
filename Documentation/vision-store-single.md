The XCTest case writes a fresh UUID request in its runner temporary directory and holds the real state for at most 120 seconds. It discovers the runner's current data container using supported fixed-device/fixed-bundle `simctl get_app_container`, reads only that UUID's request, validates the exact UI readiness record, and captures once.

The capture callback has a 100-second wall bound including 20-second reserve before each command.
